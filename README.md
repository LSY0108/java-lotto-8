# java-lotto-precourse

## 구현 기능 목록
### **1. 입력 기능**
#### 구입 금액 입력
- [x] “구입금액을 입력해 주세요.” 출력
- [x] 숫자가 아닌 값 입력 시 예외 발생
- [x] 1,000원 단위로 나누어 떨어지지 않으면 예외 발생
- [x] `[ERROR]`로 시작하는 에러 메시지 출력 후 재입력

#### 당첨 번호 입력
- [ ] “당첨 번호를 입력해 주세요.” 출력
- [ ] 쉼표(,) 기준으로 6개 번호 입력받기
- [ ] 중복되거나 1~45 범위 벗어나면 예외 발생

#### 보너스 번호 입력
- [ ] “보너스 번호를 입력해 주세요.” 출력
- [ ] 1~45 범위 숫자
- [ ] 당첨 번호와 중복되면 예외 발생

---

### 2. **로또 검증 기능**
- [ ] Lotto 객체 생성 시 번호가 6개가 아니면 예외 발생
- [ ] 번호에 중복이 있으면 `IllegalArgumentException` 발생
- [ ] 번호가 1~45 범위를 벗어나면 예외 발생

---

### 3. **로또 발행 기능**
- [ ] 구입 금액에 따라 로또 개수 계산 (`금액 / 1000`)
- [ ] 각 로또는 `Randoms.pickUniqueNumbersInRange(1, 45, 6)`으로 생성
- [ ] 생성된 모든 로또 번호를 오름차순 정렬
- [ ] 구매한 로또 수량과 각 로또 번호를 출력  

---

### 4. **당첨 결과 계산 기능**
- [ ] 각 로또와 당첨 번호 비교하여 일치 개수 계산
- [ ] 보너스 번호 일치 여부 확인
- [ ] 일치 개수와 보너스 번호에 따라 등수 판단
- [ ] 전체 당첨 내역을 저장하고 수익률 계산
- [ ] 당첨 통계와 수익률 출력  
```
당첨 통계
---
3개 일치 (5,000원) - 1개
...
총 수익률은 62.5%입니다.
```
